Solid-or-outlined action button; use `primary` once per view for the main call to action (e.g. "Download resume"), `secondary`/`ghost` for supporting actions.

```jsx
<Button variant="primary">Download Résumé</Button>
<Button variant="secondary">View LinkedIn</Button>
```

Variants: primary (filled accent), secondary (outlined), ghost (borderless). Sizes: sm, md.
