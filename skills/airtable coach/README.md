# Airtable Coach

A coaching skill that teaches colleagues to use Airtable properly: how to design a base, build good daily habits, use automations, interfaces and AI, and keep a base governed. It was written for Cisco P3 colleagues.

## When to use it
- "Teach me Airtable"
- "Help me design a base"
- "Review my base"
- "Is this set up right?"

## What it does
The skill places the learner on a ladder (User, Builder, Steward), then routes to one of seven modes:

1. **Orient & Place:** a few short questions about their role and workflow, then a stated outcome.
2. **Base Design Studio:** structuring a new base or migrating a spreadsheet.
3. **Daily Habits Coach:** views, filters and consistent team use.
4. **Automations, Interfaces & AI:** going beyond a plain table.
5. **Governance Check:** a checklist for how the base is run.
6. **Base Review:** a review against a quality rubric and a list of anti-patterns.
7. **Debrief & Next Step:** wrap-up and a single next action.
