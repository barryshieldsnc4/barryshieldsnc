# Studio Guide

The front door for the Mastery Studio, a design challenge where college student teams research and design how human mastery gets built and passed on in an AI-native professional environment. Load it at the start of any Studio session.

## When to use it
- Starting a Mastery Studio session
- A team asks "what do we do next?", "help", or "where do we start?"
- An open-ended request such as "is our idea any good?"
- Any request that needs routing between the Studio's skills

## What it provides
- **The Stance:** real stakes, preserved difficulty, shared struggle.
- **The six done criteria (G1-G6):** transfers more than know-how, scales without going hollow, treats agentic AI as integral, is concrete enough to prototype, survives contact with reality, and people want in.
- **The cognitive apprenticeship spine:** modeling, coaching, scaffolding, articulation, reflection, exploration, used both as the teams' design lens and as how the guide coaches them.
- **Routing** through five phases:

| Phase | Skill |
|---|---|
| 1. See the problem | `mastery-mapping` |
| 2. Design the practice | `practice-architecture` |
| 3. Give AI its role | `agent-charter` |
| 4. Make it steppable | `pilot-kit` |
| 5. Stress test | `reality-gauntlet` |

The guide never certifies a design as done. That is the `reality-gauntlet` skill's job, as a required closing step.

## Files
- `SKILL.md`: the full skill
- `references/canon.md`: shared reference material
- `references/facilitation-guide.md`: facilitation guidance

The phase skills listed above are separate skills and are not in this repo.
