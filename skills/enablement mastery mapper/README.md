# Enablement Mastery Mapper

A design tool for AI fluency and capability-building programs. It maps how capability with AI is actually being built, and lost, in a team today, before recommending any curriculum. The aim is a design that survives a utilization review, not just a completion dashboard.

## When to use it
- Scoping or designing an AI enablement, upskilling or adoption program
- "Design training for...", "build an enablement plan for...", "how do we get this team AI fluent"
- A brief describing low adoption despite tool access
- Someone proposes a text-first, self-paced e-learning curriculum and it needs pressure-testing

## How it works
It rests on three frameworks:
- **The AI Value Ladder** (Learn, Create, Decide, Execute, Orchestrate)
- **The Process Readiness Gate**, which checks a workflow before it becomes the thing people practice on
- **Cognitive apprenticeship** (modeling, coaching, scaffolding, articulation, reflection, exploration)

The steps are:
1. Establish the evidence base, tagging every claim as Observed, Reported or Assumed.
2. Hunt for where fluency is already being built informally and where it is being lost.
3. Map the current position on the Value Ladder.
4. Produce the Enablement Map: capability inventory, transfer mechanisms, loss and readiness ledger, ladder position and design tensions.
5. Gate every candidate practice workflow through the Process Readiness Gate.

It is standalone and does not need other skills as inputs.
