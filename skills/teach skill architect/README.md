# TEACH Skill Architect

Designs, scaffolds, writes and audits agent skills using the TEACH framework, and assigns each skill a maturity tier (Simple, Intermediate or Super Agent).

## The TEACH framework
- **T - Talent:** the brain
- **E - Enable:** the sandbox and capabilities
- **A - Approach:** the engine
- **C - Criteria:** the deliverable standards
- **H - Human Review:** the feedback loop

## Modes
1. **Guided TEACH Interview:** step-by-step through T, E, A, C and H.
2. **Fast-Track Blueprint Generator:** a quick blueprint from a short brief.
3. **TEACH Audit & Maturity Diagnosis:** audits an existing skill and classifies its maturity.
4. **Validation & Persistence:** checks the result and saves it.

## When to use it
Building a new skill, converting a prompt into a skill, or reviewing one you already have.

## Files
- `SKILL.md`: the full skill, including the quality rubric, the maturity tiers and a standard `SKILL.md` template
